# Tamil Butterfly Trails

Build a complete, production-ready Tamil butterfly photography and knowledge website.



IMPORTANT:

Use the attached/reference homepage image as the PRIMARY visual reference.

Recreate the visual design, layout, spacing, proportions, typography hierarchy, card style, colors, rounded corners, imagery treatment, navigation structure, and overall premium editorial feel as closely as possible.



Do NOT simply create a static landing page.

This must be a real, editable, content-driven website where I can continuously add butterfly photographs, short notes, and full articles in the future without changing the code.



WEBSITE PURPOSE:

A Tamil-language butterfly photography and knowledge platform.

The website should attract Tamil users who are interested in:

- Butterfly photography

- Identifying butterflies

- Short butterfly facts

- Butterfly species

- Nature

- Conservation

- Detailed articles



The design should feel:

- Elegant

- Natural

- Premium

- Minimal

- Modern

- Warm

- Visually engaging

- Easy for Tamil users to navigate



Avoid excessive colors. Use a sophisticated nature-inspired palette.



==================================================

1. DESIGN SYSTEM

==================================================



Follow the reference image closely.



Primary colors:

- Deep forest green

- Soft emerald green

- Cream / warm off-white

- Light natural beige

- Subtle pale green

- Small warm yellow/gold accents inspired by butterfly wings



Do not use too many colors.



Background:

Use warm cream/off-white as the primary background.



Typography:

Use a high-quality Tamil Unicode font with excellent readability.

The Tamil typography should look elegant and editorial, not like a generic web font.



Headings:

Large, bold, sophisticated Tamil typography.



Body:

Clean, highly readable Tamil typography.



Use generous whitespace.



Cards:

- Rounded corners

- Soft shadows

- Large photography

- Clean typography

- Subtle hover animation

- Minimal borders



Overall visual language:

Premium Tamil digital nature magazine.
